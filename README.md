# LSTM - Based Text Generation 
## **In this task, I will develop a text generator using an LSTM (Long Short-Term Memory) model. The goal is to train the model on a dataset of text sequences and generate new, coherent text based on seed input. I will work through data preprocessing, model design, training, and text generation** 

## Description
This project builds an LSTM - based text generation model using text generation model using Tensorflow/Keras. It trains on a text dataset 
and predicts the next word in a sequence.

## Technologies Used
Python 
Tensorflow/Keras
Numpy
Matplotlib 
Jupyter Notebook

## Dataset
tiny shakespeare.text dataset(.txt)

## Model
Embedding Layer
LSTM Layer
Dense Layer

## Training
optimizer :Adam
Loss : Categorial Crossentropy 
Epochs:100

## Output 
The model generates text from a given seed sentences and displays the training accuracy graph


## Note 
The Dataset base is used in this task is small through which generating text is repeating words due to overfitting of words and training dataset.
